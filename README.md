# 🛸 Mandalorian - This Is The Way Game

A Flappy Bird-inspired web game where you control the Mandalorian 🧑‍🚀, flying through obstacles in a side-scrolling adventure. This fun project mixes simple game mechanics with a **Star Wars** twist to showcase basic game development with JavaScript, HTML, and CSS.

## 🎮 Features

- Smooth and responsive controls (keyboard or tap)
- Jetpack sound effects and voice clips from the Mandalorian
- Fun, arcade-style gameplay
- Fully responsive UI using HTML & CSS
- Immersive sounds and pixel graphics

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- Audio and image assets (local)
